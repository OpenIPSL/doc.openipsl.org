OpenIPSL.Data.PowerPlant.GenerationGroup.Generator1

Generation Group for example that uses the IEEE421.5-based data set

Information

Generation group for the example that uses the IEEE421.5-based data set.

Instructions

The steps for the correct use of the data sets are indicated below:

  1. Drag and Drop an instance of a OpenIPSL.Data.PowerPlant.GUDynamics record to the diagram layer of your generation group model.
  2. Propagate the GUnitDynamics parameter of the GUDynamics record.
  3. Go to the upper-level model that contains an instance of this generation group (e.g., IEEE421 example model). Complete the local instructions and come back to continue with step 4.
  4. Insert component references inside the parameter fields of the Synchronous Machine, Excitation System and Power System Stabilizer blocks. For example, to specify the inertia constant of the GENSAE synchronous machine (i.e., H), you must fill its field with this expression: gUDynamics.guDynamics.machine.H. To do this, you can either type the value or recreate the whole path, by first clicking the Insert Component Reference option and then navigating the references accordingly.

Extends from OpenIPSL.Electrical.Essentials.pfComponent (Partial model containing all the parameters for entering power flow data).
