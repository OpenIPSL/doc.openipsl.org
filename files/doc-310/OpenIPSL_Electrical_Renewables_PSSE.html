OpenIPSL.Electrical.Renewables.PSSE.BESS

Framework for a battery energy storage system plant including controllers

Information

This model is meant as a simple framework to create a battery energy storage system plant that consists of:

  • Generator/Converter
  • Electrical Controller
  • Plant Controller

The type of each can be selected via a drop down list where also a deactivation is provided (normally via feed through).

The type of control configuration can also be selected via drop down list.

Extends from OpenIPSL.Electrical.Essentials.pfComponent (Partial model containing all the parameters for entering power flow data).

OpenIPSL.Electrical.Renewables.PSSE.Wind

Framework for a wind plant including controllers

Information

This model is meant as a simple framework to create a wind power plant that consists of:

  • Generator/Converter
  • Electrical Controller
  • Plant Controller
  • Drive Train

The type of each can be selected via a drop down list where also a deactivation is provided (normally via feed through).

The type of control configuration can also be selected via drop down list, with or without the torsional modeling of the drive train component.

Extends from OpenIPSL.Electrical.Essentials.pfComponent (Partial model containing all the parameters for entering power flow data).
